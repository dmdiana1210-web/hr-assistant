# Отчёт по мониторингу рыночного уровня заработной платы ключевых сотрудников

## Назначение отчёта
Ежемесячный мониторинг рыночного уровня ЗП по 12 ключевым сотрудникам компании. Цель — своевременно заметить, когда зарплата ключевого сотрудника падает ниже рынка, и предотвратить риск ухода.

## Важное о конфиденциальности
Реальные зарплаты сотрудников в этом отчёте **не хранятся** — это конфиденциальная информация. Отчёт содержит только рыночные ориентиры. Сравнение с реальными суммами пользователь выполняет самостоятельно в отдельном (локальном, не коммитимом) экземпляре файла.

## Пороги риска (для самостоятельной оценки)
- ✅ **В рынке** — текущая ЗП в диапазоне ±5% от рыночной средней.
- ⚠️ **Ниже рынка** — текущая ЗП ниже рыночной средней более чем на 10%.
- 🔴 **Критично (риск ухода)** — текущая ЗП ниже рыночной средней более чем на 20%.

## Источник данных
- **Основные площадки из запроса (HH, SuperJob, Rabota.ru, Zarplata.ru):** автоматический сбор недоступен — сайты блокируют программные запросы (подтверждено в предыдущем мониторинге). По всем четырём площадкам — «Нет данных».
- **Фактический источник:** открытое API государственной базы вакансий «Работа в России» (trudvsem.ru). Источник **не входит** в исходный список площадок и приведён как единственный доступный автоматический источник.

## Важное о формате сумм (НДФЛ)
Источник trudvsem.ru **не уточняет**, в каком формате опубликованы суммы — до или после вычета НДФЛ. Подтверждённых данных для пересчёта нет, поэтому суммы приведены в том виде, в котором их указал источник. Приведение к единому формату «до вычета НДФЛ» без подтверждённого исходного формата не выполняется — это отмечено по каждой позиции.

## Параметры мониторинга
- **Регион:** Чувашская Республика (по Сотруднику 9 — Республика Татарстан, г. Лениногорск).
- **Учитывались:** только вакансии с релевантным названием должности и близкими обязанностями.
- **Отсев:** линейные позиции (водитель, продавец, монтажник и т. п.) исключены; для руководящих должностей дополнительно отсеяны нерелевантные руководители (директор магазина, мастер-приемщик).

## Вывод

Мониторинг выполнен по всем 12 ключевым сотрудникам. Данные получены из единственного доступного автоматического источника — открытой базы «Работа в России» (trudvsem.ru), так как основные площадки (HH, SuperJob, Rabota.ru, Zarplata.ru) блокируют автоматический сбор.

**Качество данных:**
- **Надёжная выборка (≥10 вакансий):** Сотрудник 4 (Главный бухгалтер, 16 вакансий), Сотрудник 6 (Финансовый аналитик, 27 вакансий), Сотрудник 12 (HR, 10 вакансий). По этим должностям рыночный коридор наиболее точен.
- **Малая выборка (1–3 вакансии):** Сотрудники 1, 2, 5, 7, 8, 9, 10, 11. Статистика ориентировочная и не отражает полный рынок — нужны дополнительные данные.
- **Нет данных:** Сотрудник 3 (Руководитель транспортного направления) — релевантных руководящих вакансий в Чувашии не найдено.

**Ограничения:**
- Все суммы приведены в формате источника, так как trudvsem.ru не уточняет, до или после вычета НДФЛ они указаны. Приведение к единому формату «до вычета НДФЛ» не выполнялось.
- Малая выборка по большинству должностей снижает точность рыночной оценки.
- Данные по HH, SuperJob, Rabota.ru, Zarplata.ru отсутствуют, поэтому полноценная конкурентная оценка по заявленному списку площадок невозможна.

## Рекомендации

1. **По должностям с малой выборкой (1–3 вакансии):** рыночный коридор ориентировочен. Рекомендуется дополнить мониторинг ручным сбором данных по HH, SuperJob, Rabota.ru, Zarplata.ru — открыть каждую площадку, отфильтровать по региону, оставить вакансии с близкими обязанностями и зафиксировать зарплаты.
2. **По Сотруднику 3 (Руководитель транспортного направления):** данных нет. Рекомендуется ручной сбор по вакансиям «начальник автоколонны», «руководитель транспортного отдела», «логист-руководитель» на основных площадках.
3. **Уточнение формата НДФЛ:** в карточках вакансий (в том числе на trudvsem.ru) проверить, указаны ли суммы до вычета НДФЛ или «на руки», и при необходимости привести к единому формату. Пересчёт выполнять только при подтверждённом исходном формате.
4. **По должностям с надёжной выборкой (Главный бухгалтер, Финансовый аналитик, HR):** рыночный коридор можно использовать для сравнения с текущими зарплатами сотрудников и оценки риска ухода по порогам, указанным в начале отчёта.
5. **Периодичность:** мониторинг рекомендуется проводить ежемесячно, запуская Claude Code с запросом «Обнови мониторинг по ключевым сотрудникам».
