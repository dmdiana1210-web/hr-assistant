# Сводный мониторинг рыночного уровня заработной платы по ключевым позициям

## Назначение отчёта

Пилотный сводный мониторинг по нескольким ключевым позициям компании. Цель — конкурентная оценка: увидеть рыночный коридор заработной платы по каждой позиции в одном отчёте и быстро сравнить с уровнем компании. Отчёт объединяет формат разбивки по площадкам (как в отчёте по одной должности) и сводную картину по нескольким позициям сразу.

В пилот включены 5 позиций, выбранных по разнообразию направлений и качества данных. После pilots формат можно распространить на все позиции из реестра.

## Общие параметры

- **Регион:** Чувашская Республика.
- **Основные площадки из запроса:** HeadHunter, SuperJob, Rabota.ru, Zarplata.ru.
- **Фактический источник (справочно):** открытое API государственной базы вакансий «Работа в России» (trudvsem.ru). Источник **не входит** в исходный список площадок и приведён как единственный доступный автоматический источник.
- **Учитывались:** только вакансии с релевантным названием должности и близкими обязанностями.
- **Отсев:** линейные позиции (без подчинённых) исключены с кратким пояснением; для должности «Системный администратор» сделано обоснованное исключение (ключевой сотрудник по запросу пользователя).

## Важное о формате сумм (НДФЛ)

Все рыночные суммы в отчёте приводятся **до вычета НДФЛ** (gross). Источник trudvsem.ru **не уточняет**, в каком формате опубликованы суммы — до или после вычета НДФЛ. Подтверждённых данных для пересчёта нет, поэтому пересчёт к gross не выполняется — это отдельно отмечено по каждой позиции. Опубликованные суммы приведены в том виде, в котором их указал источник.

Текущие зарплаты действующих сотрудников в отчёте **не хранятся** — это конфиденциальная информация. Колонка «Ваша ЗП» заполняется пользователем самостоятельно в отдельном (локальном, не коммитимом) экземпляре файла.

## Площадки: статус автоматического сбора

По всем четырём заявленным площадкам автоматический сбор недоступен — подтверждено в предыдущих мониторингах:

- **HeadHunter** — поиск отдаёт данные только через JavaScript, публичное API возвращает ошибку 403 без авторизации.
- **SuperJob** — автоматический запрос возвращает только московские вакансии, по Чувашии данных нет.
- **Rabota.ru** — сервер возвращает ошибку 400, автоматический сбор невозможен.
- **Zarplata.ru** — сервер возвращает ошибку 404, автоматический сбор невозможен.

По всем четырём площадкам в пилотных блоках ниже проставлено «Нет данных». Рыночные коридоры рассчитаны по справочному источнику trudvsem.ru.

## Общий вывод

Пилотный сводный мониторинг выполнен по 5 ключевым позициям из 5 разных направлений (финансы, HR, продажи, IT, маркетинг). По всем четырём заявленным площадкам (HeadHunter, SuperJob, Rabota.ru, Zarplata.ru) данные получить автоматически не удалось — все они помечены «Нет данных». Рыночные коридоры рассчитаны по справочному источнику trudvsem.ru.

**Качество данных:**
- **Надёжная выборка (≥10 вакансий):** Главный бухгалтер (16), HR (10). По этим позициям рыночный коридор наиболее точен.
- **Малая выборка (1–3 вакансии):** Руководитель отдела продаж (1), Системный администратор (3), Маркетолог (1). Статистика ориентировочная и не отражает полный рынок.

**Ограничения:**
- Все суммы приведены в формате источника, так как trudvsem.ru не уточняет, до или после вычета НДФЛ они указаны. Приведение к единому формату «до вычета НДФЛ» не выполнялось.
- Малая выборка по 3 из 5 позиций снижает точность рыночной оценки.
- Данные по заявленным площадкам отсутствуют, поэтому полноценная конкурентная оценка до вычета НДФЛ невозможна.
- По должности HR в выборке смешаны линейные и руководящие кадровые позиции — средняя смещена.

## Общие рекомендации

1. **По должностям с надёжной выборкой (Главный бухгалтер, HR):** рыночный коридор можно использовать для конкурентной оценки. По HR предварительно разделить вакансии на линейные и руководящие.
2. **По должностям с малой выборкой (РОП, Системный администратор, Маркетолог):** рыночный коридор ориентировочен. Рекомендуется дополнить мониторинг ручным сбором по HH, SuperJob, Rabota.ru, Zarplata.ru — отфильтровать по региону, оставить вакансии с близкими обязанностями, зафиксировать зарплаты до вычета НДФЛ.
3. **Уточнение формата НДФЛ:** в карточках вакансий проверить, указаны ли суммы до вычета НДФЛ или «на руки», и при необходимости привести к единому формату. Пересчёт выполнять только при подтверждённом исходном формате.
4. **Расширение пилота:** после успешной отработки формата распространить мониторинг на остальные позиции из реестра ключевых сотрудников.
5. **Периодичность:** мониторинг рекомендуется проводить регулярно, запуская Claude Code с запросом «Обнови сводный мониторинг по ключевым позициям».
