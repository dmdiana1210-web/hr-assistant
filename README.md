# HR Assistant

HR Assistant — проект для мониторинга рынка труда: собирает данные о
зарплатах по вакансиям конкурентов и формирует понятные отчёты для
руководства с рекомендацией по конкурентной оплате. Помогает HR-специалисту
быстро сравнить уровень оплаты по площадкам и принять решение.

**Вспомогательные HR-автоматизации (хранятся здесь же, вне основного scope):**
- `Отсутствия/` — автоотметка отсутствий: утверждённые в Битрикс24 заявления
  попадают в Google-таблицу «Отпуска» и в «График отсутствий». Рабочая версия
  — в Google Apps Script, здесь копия кода и инструкция. Секреты хранятся
  только в «Свойствах скрипта».
- `Отпуска в профиле/` — остаток отпуска из Google-таблицы в профиль
  Битрикс24, в первый рабочий день месяца. Рабочая версия — в Google Apps
  Script, здесь копия кода (вебхук и ссылка на таблицу заменены заглушками).
- `Опросник личных дел/` — рассылка опросника сотрудникам, сверка ответов и
  запись в личные дела. Настройки (`nastroyki.json`), списки сотрудников и
  отчёты в git не сохраняются.
- `BirthdayGreetings/` — поздравления сотрудников с днём рождения. Ключи
  (`config.json`) в git не сохраняются.

Секреты, списки сотрудников и выгрузки с персональными данными в git не
попадают — см. `.gitignore`.

**На будущее (не входят в текущий проект):**
- анализ действующих сотрудников;
- контроль на наличие резюме действующих сотрудников в открытых источниках;
- написание HR-постов;
- помощь в подборе персонала.
