## Задача 1. Инструкция для нового сотрудника на первый рабочий день

### Версия 1

Напиши инструкцию для нового сотрудника на первый рабочий день.

### Версия 2

# Контекст

Новый сотрудник выходит на первый рабочий день. Нужна инструкция, которая проведёт его от подготовки документов до подведения итогов дня. Инструкция должна быть краткой, чтобы сотрудник быстро её прочитал, но достаточно полной, чтобы покрыть оформление, рабочее место, доступы, инструктажи и итоговую проверку. В компании используется мониторинг зарплат по площадкам HH, SuperJob, Rabota.ru, Zarplata.ru с указанием сумм до вычета НДФЛ — если работа сотрудника связана с аналитикой зарплат, инструкция должна кратко упомянуть этот процесс.

# Ссылки

- Запрос на мониторинг зарплат — materials/salary-request.md
- Отчёт по мониторингу зарплат — materials/salary-report.md
- Чек-лист проверки вакансии — materials/vacancy-review.md
- Правила проекта — CLAUDE.md

# Задача

Подготовить инструкцию для нового сотрудника на первый рабочий день. Инструкция ведёт сотрудника по шагам: от подготовки документов до подведения итогов дня.

# Формат

Инструкция, объём до 700 слов. Структура — шесть частей:

- вступление;
- до начала рабочего дня (документы, что уточнить у HR);
- первая половина дня (встреча с HR, знакомство с командой, наставник, рабочее место, доступы, инструктажи);
- вторая половина дня (изучение материалов, разбор первых задач, вопросы по процессам);
- что проверить перед завершением дня;
- итоговый чек-лист.

Тон — тёплый и понятный, без канцелярита.

# Ограничения

1. Не вписывать реальные персональные данные — ФИО, телефоны, адреса, расписания. Использовать плейсхолдеры `[заполнить: …]`.
2. Объём — не более 700 слов.
3. Суммы упоминать только до вычета НДФЛ.
4. Сохранить привязку к процессам компании: площадки HH, SuperJob, Rabota.ru, Zarplata.ru.
5. Не придумывать процессы, которых нет в материалах проекта.

# Верификация

Перед сдачей проверить готовую инструкцию по чек-листу:

1. **Объём** — инструкция содержит не более 700 слов.
2. **Структура** — присутствуют все шесть частей: вступление, до начала дня, первая половина, вторая половина, проверка перед завершением, итоговый чек-лист.
3. **Персональные данные** — все ФИО, телефоны, адреса, расписания заменены плейсхолдерами `[заполнить: …]`; реальных персональных данных нет.
4. **Зарплата** — упоминание сумм (если есть) дано до вычета НДФЛ.
5. **Привязка к компании** — упомянуты площадки HH, SuperJob, Rabota.ru, Zarplata.ru при описании мониторинга зарплат.
6. **Чек-лист** — в конце есть итоговый чек-лист первого дня.

Если хотя бы один пункт проверки не выполнен, сначала исправь найденные замечания, затем повторно проверь инструкцию по этому чек-листу и только после успешной проверки покажи итоговый результат.

## Задача 2. Переработка отчёта по зарплатам

### Версия 1

Сделай отчёт по мониторингу зарплат руководителя отдела продаж в Чувашии.

### Версия 2

# Контекст

Подготовлен отчёт по мониторингу зарплат руководителя отдела продаж в Чувашской Республике. По четырём заявленным площадкам (HH, SuperJob, Rabota.ru, Zarplata.ru) данные получить автоматически не удалось — по всем «Нет данных». Как справочный источник использована государственная база «Работа в России» (trudvsem.ru) с открытым API — найдены 2 релевантные руководящие вакансии. Предыдущая версия отчёта пересчитывала опубликованные суммы к gross по допущению (gross = net / 0,87), но источник не уточняет, в каком формате опубликованы суммы — до или после вычета НДФЛ. Подтверждённых данных для пересчёта нет, поэтому пересчёт некорректен и должен быть удалён.

# Ссылки

- Запрос на мониторинг зарплат — materials/salary-request.md
- Предыдущая версия отчёта — materials/salary-report.md
- Правила проекта — CLAUDE.md

# Задача

Переработать отчёт по мониторингу зарплат: убрать неподтверждённый пересчёт net → gross и все основанные на нём gross-цифры. Опубликованные суммы оставить в исходном виде. Для средней, минимальной и максимальной зарплаты до вычета НДФЛ указать «Недостаточно данных». Сохранить раздельное представление четырёх площадок и отметку об отклонении линейной вакансии.

# Формат

Структурированный отчёт. Сохранить разделы: Должность, Регион, Параметры запроса, Результаты мониторинга (отдельно по HH, SuperJob, Rabota.ru, Zarplata.ru), Дополнительный источник trudvsem.ru, Сводные показатели (отдельно по заявленным площадкам и справочно trudvsem.ru), Вывод, Рекомендация. В блоке о формате сумм явно указать, что пересчёт к gross не выполняется. Все суммы указывать до вычета НДФЛ.

# Ограничения

1. Не выполнять пересчёт net → gross без подтверждённого исходного формата.
2. Не указывать конкретные gross-цифры (68 966, 114 943, ~92 000) как достоверные.
3. Для средней/мин/макс «до вычета НДФЛ» — «Недостаточно данных», если пересчёт невозможен.
4. Не формировать рекомендацию по конкурентной зарплате до вычета НДФЛ при отсутствии подтверждённых данных.
5. Сохранить отклонение линейной вакансии с кратким объяснением.
6. Не придумывать данные по зарплатам — писать «Нет данных».

# Верификация

Перед сдачей проверить готовый отчёт по чек-листу:

1. **Пересчёт** — в отчёте нет формулы `gross = net / 0,87` и пересчитанных gross-сумм (68 966, 114 943, ~92 000).
2. **Опубликованные суммы** — оставлены в исходном виде («от 100 000 ₽», «от 60 000 до 100 000 ₽»).
3. **Показатели** — для средней/мин/макс «до вычета НДФЛ» указано «Недостаточно данных».
4. **Площадки** — результаты по HH, SuperJob, Rabota.ru, Zarplata.ru показаны раздельно, по всем «Нет данных».
5. **Рекомендация** — конкурентная рекомендация «до вычета НДФЛ» не сформирована.
6. **Линейная вакансия** — отклонена с кратким объяснением (линейная позиция, нет подчинённых).

Если хотя бы один пункт проверки не выполнен, сначала исправь найденные замечания, затем повторно проверь отчёт по этому чек-листу и только после успешной проверки покажи итоговый результат.

## Задача 3. Чек-лист проверки текста вакансии

### Версия 1

Сделай чек-лист проверки текста вакансии перед публикацией.

### Версия 2

# Контекст

В компании есть чек-лист проверки текста вакансии перед публикацией. Текущая версия чек-листа базовая: в ней нет отдельной проверки формата и графика работы, нет проверки на отсутствие персональных и чувствительных данных, а формулировки некоторых пунктов недостаточно конкретны. HR-отдел хочет доработать чек-лист: добавить недостающие разделы, сделать каждый пункт измеримым (да/нет) и добавить проверку на отсутствие персональных данных сотрудников.

# Ссылки

- Действующая версия чек-листа — materials/vacancy-review.md
- Правила проекта — CLAUDE.md

# Задача

Доработать чек-лист проверки текста вакансии. Добавить разделы «Формат и график работы» и «Отсутствие персональных и чувствительных данных». Уточнить формулировки пунктов, чтобы по каждому можно было однозначно ответить «да» или «нет». Во вступлении указать, что по каждому пункту ставится отметка «да» или «нет».

# Формат

Чек-лист с флажками `- [ ]`. Структура: вступление, разделы проверки (Название должности, Обязанности, Требования, Условия работы, Заработная плата, Формат и график работы, Грамотность и понятность текста, Отсутствие персональных и чувствительных данных), итог. По каждому пункту — измеримый признак.

# Ограничения

1. Каждый пункт должен допускать однозначный ответ «да» или «нет».
2. Не использовать размытые формулировки без измеримого признака.
3. Не вписывать реальные персональные данные — ФИО, телефоны, адреса, паспортные данные, ИНН, СНИЛС, зарплаты действующих сотрудников.
4. Суммы зарплат указывать до вычета НДФЛ.
5. Сохранить назначение документа — проверка вакансии перед публикацией.

# Верификация

Перед сдачей проверить готовый чек-лист по чек-листу:

1. **Разделы** — присутствуют разделы «Формат и график работы» и «Отсутствие персональных и чувствительных данных».
2. **Да/нет** — во вступлении указано, что по каждому пункту ставится отметка «да» или «нет».
3. **Измеримость** — каждый пункт сформулирован так, что по нему можно однозначно ответить «да» или «нет».
4. **Персональные данные** — есть пункты, проверяющие отсутствие ФИО, телефонов, адресов, паспортных данных, ИНН, СНИЛС, зарплат действующих сотрудников.
5. **Зарплата** — в разделе «Заработная плата» требуется указание суммы до вычета НДФЛ.
6. **Итог** — в конце есть раздел «Итог» с инструкцией, что делать при невыполнении пунктов.

Если хотя бы один пункт проверки не выполнен, сначала исправь найденные замечания, затем повторно проверь чек-лист по этому чек-листу и только после успешной проверки покажи итоговый результат.
