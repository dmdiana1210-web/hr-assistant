# HR Assistant

## WHY

Этот проект помогает автоматизировать ежедневные HR-задачи и сократить время на подготовку аналитики по заработным платам. Основная цель — быстро проводить мониторинг рынка труда и формировать понятные отчеты для руководства.

## WHAT

Проект собирает данные о зарплатах по вакансиям конкурентов с нескольких
площадок (HH, SuperJob, Rabota, Zarplata) и сводит их в аналитический отчёт
для руководства с рекомендацией по конкурентной заработной плате. Все суммы
указываются до вычета НДФЛ.

## На будущее

Эти направления не входят в текущую версию проекта, но могут быть добавлены
на следующих ступенях:

- анализ действующих сотрудников;
- контроль на наличие резюме наших действующих сотрудников;
- написание HR-постов;
- помощь в подборе персонала.

## HOW

При работе над проектом придерживайся следующих правил:

1. Никогда не придумывай данные по заработной плате. Если информации нет — напиши «Нет данных».

2. Используй только вакансии с максимально похожими обязанностями.

3. Все суммы указывай **до вычета НДФЛ**, если пользователь не попросил иначе.

4. Отдельно показывай результаты по каждой площадке (HH, SuperJob, Rabota, Zarplata).

5. В конце каждого мониторинга обязательно делай вывод и рекомендацию по конкурентной заработной плате.

6. Все отчеты оформляй структурировано с заголовками и списками.

7. Если данных недостаточно, сначала сообщи об этом, а не делай предположений.

8. Бери в анализ только руководящие позиции. Линейные позиции (без подчинённых) отбрасывай и кратко объясняй, почему не взял.

9. Не вписывай реальные персональные данные — ФИО, телефоны, адреса, паспортные данные, ИНН, СНИЛС, зарплаты действующих сотрудников. Вместо конкретных значений используй плейсхолдеры вида `[заполнить: …]` или обобщающие категории.

10. Формулируй каждый пункт и критерий так, чтобы по нему можно было однозначно ответить «да» или «нет». Не используй размытые формулировки без измеримого признака («текст должен быть хорошим», «вакансия должна быть привлекательной»).
