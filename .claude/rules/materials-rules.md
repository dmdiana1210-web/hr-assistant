# Правила оформления материалов

Действует при работе с любыми файлами в `materials/`.

1. Формулируй каждый пункт и критерий так, чтобы по нему можно было
   однозначно ответить «да» или «нет». Не используй размытые формулировки без
   измеримого признака («текст должен быть хорошим», «вакансия должна быть
   привлекательной»).
