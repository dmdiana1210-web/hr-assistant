# Правила зарплатного мониторинга

Эти правила действуют при работе с зарплатными отчётами и мониторингом по
ключевым позициям. Глобальные правила (не придумывать данные, не вписывать
персональные данные) — см. `CLAUDE.md`.

1. Бери в анализ только вакансии с максимально похожими обязанностями. Если
   обязанности сильно отличаются — вакансию не учитывай.

2. Отдельно показывай результаты по каждой площадке (HH, SuperJob, Rabota,
   Zarplata). Не своди всё в одну усреднённую цифру без разбивки.

3. Бери в анализ только руководящие позиции. Линейные позиции (без
   подчинённых) отбрасывай и кратко объясняй, почему не взял.

4. В конце каждого мониторинга делай вывод. Рекомендацию по конкурентной
   заработной плате формируй **только** при наличии достаточных
   подтверждённых данных. Если данных мало — в рекомендации прямо укажи, на
   чём она основана и насколько она надёжна.

5. Достаточность подтверждённых данных для рекомендации определяется порогами:

   - Вакансий в расчёте: ≥ 10 — рекомендация надёжная; 1–9 — предварительная,
     с прямой оговоркой «выборка мала (N)»; 0 — рекомендация не формируется.
   - Формат НДФЛ: суммы должны быть приведены к «до вычета НДФЛ» (gross) по
     подтверждённому исходному формату. Если источник не уточняет gross/net —
     пересчёт не выполняется, рекомендация «до вычета НДФЛ» не формируется,
     опубликованные суммы приводятся только справочно.
   - Площадки: данные минимум с 1 площадки из заявленного списка (HH, SuperJob,
     Rabota, Zarplata). Справочный сторонний источник (trudvsem.ru и подобный)
     не подменяет заявленные площадки и не даёт основы для рекомендации.
   - Частичные «Нет данных»: если по части площадок данных нет — расчёт ведётся
     по тем, где данные есть, но в рекомендации явно указывается, по скольким
     площадкам из заявленных есть данные и по скольким их нет.

   Если пороги не выполнены — в рекомендации прямо написать, какой именно порог
   не достигнут и что нужно для уверенной рекомендации.
